Second brain inbox

Put here whatever you want the AI to read and keep: a PDF, text copied from a website, a transcript, a screenshot. You can drag the file here {{gerenciador}} or from inside Obsidian.

Once a day, if there's a new file here, the AI reads each one, writes a summary in the sources folder and keeps the ideas that matter. Then the file goes to the processed subfolder. Nothing gets deleted. If you want it right away, open the AI and ask: /save.

If you use Obsidian Web Clipper, Obsidian's browser extension, you can send web pages straight here: in the extension's options, change the folder where it saves to CLAUDE/inbox.
