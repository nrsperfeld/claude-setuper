Pasta de entrada do segundo cérebro

Coloque aqui o que você quer que o Claude leia e guarde: um PDF, um texto copiado de um site, uma transcrição, um print. Dá pra arrastar o arquivo pra cá {{gerenciador}} ou pelo próprio Obsidian.

Uma vez por dia, se tiver arquivo novo aqui, o Claude lê cada um, escreve um resumo na pasta fontes e guarda as ideias que importam. Depois o arquivo vai pra subpasta processados. Nada é apagado. Se quiser na hora, abra o Claude e peça: /guardar.

Se você usa o Obsidian Web Clipper, a extensão do Obsidian pro navegador, dá pra mandar páginas da internet direto pra cá: nas opções da extensão, troque a pasta onde ela salva para CLAUDE/inbox.
